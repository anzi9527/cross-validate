## 💰 赚钱信号

### 机会 1：垂直场景 AI 客服机器人（视觉售后方向）
- **痛点**：传统售后客服无法“看见”故障实物，用户描述不清、远程诊断难，退货率与售后成本双高 [推理，基于36氪该新产品的逻辑]
- **方案**：针对家电、消费电子等品类，做 AI 视觉识别 + 售后故障诊断的 SaaS 工具，或直接面向品牌方提供 API 接口 [推理]
- **门槛**：机器视觉技术积累 + 垂直行业故障数据；资金门槛中等（可先做轻量 API 方案）[推理]
- **竞争**：蓝海——全球首款产品刚发布，国内尚无同体量竞品报道 [数据来源+推理]
- **我的建议**：值得密切关注。最好的切入点不是做通用客服，而是选择**一个**具体品类（如打印机、新能源车充电桩）打穿 [推理]

### 机会 2：AI 减肥/健康情绪陪伴应用
- **痛点**：年轻人深夜饮食冲动、情绪性进食，传统减重 App 缺乏共情能力和即时响应；凌晨 2 点找不到人倾诉 [数据来源：36氪「吃完就后悔的年轻人，把凌晨2点的AI当成了减肥树洞」]
- **方案**：做一个 AI 陪伴式减重助手：情绪识别对话 + 饮食/运动管理 + “吃完后悔了怎么办”的痛苦承接场景 [数据来源+推理]
- **门槛**：产品设计能力 > 技术门槛（现成大模型 API 即可）；关键在话术语料与“树洞感”的体验打磨 [推理]
- **竞争**：蓝海边缘转红海——减重 App 竞争激烈，但“AI 情绪陪伴 + 减重”的细分心智尚无人占住 [推理]
- **我的建议**：轻量启动首选微信小程序，小红书种草切入，靠深夜场景话题出圈 [推理]

### 机会 3：AI 游戏应用
- **痛点**：玩家想要更智能的 NPC、更动态的剧情；游戏厂商需要降本增效 [数据来源：36氪「中国游戏，进入'与AI同游'时代」]
- **方案**：给中小游戏团队提供 Agent 接入中间层（对话 NPC、AI 副本生成），或做 AI 游戏 UGC 工具 [推理]
- **门槛**：游戏行业理解 + 大模型技术结合能力 [推理]
- **竞争**：红海早期——大厂已入局，但中小游戏公司大量未接入 [推理]
- **我的建议**：普通个人开发者慎入，除非有游戏行业资源；更轻的方案是面向玩家的“AI 陪伴同游”工具 [推理]
